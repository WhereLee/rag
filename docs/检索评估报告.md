## 2. 四组对比 Recall@5（黄金集 25 条）

| 方案 | 命中 | Recall@5 |
|------|-----:|---------:|
| 纯向量（bge-base-zh） | 19 | 76.00% |
| 纯 BM25（jieba + rank_bm25） | 22 | 88.00% |
| RRF 融合（k=60） | 24 | 96.00% |
| **RRF + rerank（v2-m3）** | **25** | **100.00%** |

分类型（RRF+rerank）：专有名词类 19/19 = 100%；语义近义类 6/6 = 100%。
（类别定义：专有名词=编号/人名/技术名精确匹配；语义近义=同义改写，刻意覆盖两类弱点）

结论：**RRF 优于任一单路（96% ≥ max(76%, 88%)），rerank 补齐最后 4 个百分点**——单路在专有名词（BM25 强）或语义改写（向量强）上各有盲区，融合是必要项而非锦上添花。

## 4. 低分拒答阈值标定建议

当前实现：`RERANK_REJECT = -5.0`（规范 LT-S 001-2026 §4.2 原文值），`RERANK_LOW = 0.0`。

- **维持 -5.0 作为剔除线**：抽查中所有可答问题的 top1 rerank 分数均 > 0，正样本与 -5 有充分间隔；拒答路径（检索无结果/低置信）全部正确触发
- 0.2 归一化分数方案不可行（计划初值）：bge-reranker-v2-m3 输出 logits 绝对分（跨查询可比），softmax 归一化是相对概率不可比；-5.0 是规范§4.2 既定值，与黄金集实测不冲突
- 低置信线 0.0 偏保守：抽查中 1 例（Q2）top1 分数 -0.16 仍答对，`low_confidence` 仅作 meta 标记不拒答，行为正确

## 5. 已知问题清单

1. **【已识别 · 演进项】跨语言查询召回盲区**：中文问题查英文文档（fastapi/mineru README）时，答案块不在向量/BM25 top50 内（bge-base-zh 中英语义空间差异 + 英文高频词稀释 BM25 排名），LLM 依据不充分上下文正确拒答（安全但体验差）。处理方向：查询改写/中英互译、英文块注入中文摘要元数据。
2. **【已识别 · 演进项】rerank top5 窗口挤出弱表述答案块**：含确切答案的块在融合候选第 11 位，被 rerank top5 挤出（Q12 场景）。处理方向：动态 top_k、父子块检索、答案块溯源展示。
3. **【已识别 · 低危】HTML 文档块噪声**：README 类文档大量 img/link 行成块（mineru 159 块），信息密度低，占用召回窗口。处理方向：R1 cleaner 对 html 标签行做丢弃（演进项）。
4. **【已解决】SSE 流式 delta 拆包导致文本断言失真**：`QA_MARK_2026` 被拆成 3 个 delta 事件，测试需拼接后断言（C4 修复）。
5. **【已解决】网关上游不可达时静默空响应**：QaController 补发 error 事件（C4 修复）。
